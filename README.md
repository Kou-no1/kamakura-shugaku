# 鎌倉たびクエスト

鎌倉・江の島の修学旅行を準備する、探究型の学習サイトです。小学校6年生・班での事前学習を想定しています。

## 学び方

児童が地図上で見学先を選び、キャラクターを道に沿って移動させます。見学先の歴史・自然・暮らしのエピソードから問いを考え、発見を記録します。

**時間・運賃・交通費の合計は自動で計算しません。**

- 徒歩：資料や地図を調べ、出発時刻・到着予定時刻・移動時間・根拠を児童が入力します。
- 江ノ電：先生が設定した切符購入時間を条件に、購入終了時刻・乗る電車の発車時刻・到着時刻・運賃を児童が調べます。
- 段階的なヒントは、縮尺、歩く速さ、平日／土休日、方向、購入・待ち時間などに目を向けさせます。
- 「見直すポイント」は児童の時刻同士の整合性だけを確認します。正解の時間や運賃は出しません。公式の運行や道路状況を判定する機能ではありません。
- ノートで修正すると、前の予想と根拠を残したまま更新できます。過去の移動を修正しても、後続の移動時刻は自動変更しません。班で後続の計画も見直します。
- 見学を終えたらスタンプを押します。必須ポイントをすべて見学してゴールの見学を終えると、見学ミッション達成となります。時間・予算・根拠の妥当性は別途振り返ります。

初期教材には23地点があります。出発は鶴岡八幡宮、必須ポイントは鎌倉大仏と江ノ島駅、ゴールは新江ノ島水族館です。

## 先生の準備室

1. 出発・ゴール・必須チェックポイント、出発／集合時刻、切符購入時間、交通費予算、発見メモの必須条件を設定します。
2. 各場所の写真（4枚まで）、エピソード、問い、マナー、参考URLを編集します。写真は端末内で縮小されます。新規地点も緯度・経度で追加できます。
3. 「教材を配布」から教材HTMLまたは教材JSONを書き出します。教材に児童の班名や回答は含めません。
4. 新しい教材HTMLを `index.html` にして配布・公開します。教材JSONを配る場合は、児童の端末で先生の準備室から読み込みます。

先生の準備室は教材作成用の画面で、パスワード付きの管理サーバーではありません。GitHub上のファイルは、ここで編集しても自動更新されません。

## GitHub Pagesで公開

インストールやAPIキーは不要です。

1. GitHubの公開したいリポジトリのルートに、このプロジェクトの `index.html`、`icon` フォルダ、`site.webmanifest`、`.nojekyll` を配置します。
2. Settings → Pages → Build and deployment で、Deploy from a branch を選びます。
3. Branch を `main`、フォルダーを `/ (root)` にして保存します。
4. 表示されたPagesのURLを児童に配ります。

先生が作った教材HTMLを `index.html` に置き換えるだけでも使えます。写真・アプリのコードを含む単一HTMLです。ファイルを直接開いても模式図と学習機能は使えますが、ローカルファイルからの保存可否は端末のブラウザーに依存します。授業ではHTTPSでの利用を推奨します。

## 記録と提出

- 各端末のブラウザーに自動保存します。先生や他の班とのリアルタイム同期、サーバー上の児童一覧はありません。
- ノートからJSONを書き出して、学校の提出方法で渡せます。同じ教材では記録を読み込んで再開できます。
- 印刷・PDF保存に対応しています。
- ブラウザーのデータ削除、プライベートモード、端末交換に備え、授業の区切りで記録を書き出してください。
- 班名・文章・写真はアプリから自動送信しません。実地図や外部資料を開く際は、外部サイトへの通常の通信が発生します。

## 地図

模式図と実地図は同じ緯度経度をもとに地点を表示します。キャラクターは地図を切り替えても同じ地点にいます。拡大後は背景をドラッグして移動できます。小さい画面では出発地点付近を拡大表示します。矢印キーと画面の方向ボタンでは、現在の地点につながる道を選べます。自由な方向に海や山を横断する方式ではありません。

模式図の道は事前学習用です。実際の歩行ルートや通行可否を表していません。江ノ電の一部途中駅は省略しています。移動アニメーションの長さは実際の所要時間ではありません。

実地図はオンライン時に国土地理院の標準地図タイルを表示します。出典を地図上に明示しています。タイル一覧：https://maps.gsi.go.jp/development/ichiran.html 。事前取得・一括取得・オフライン用保存は行いません。ローカルファイルからは地図タイルを読み込みません。

GoogleマップとGoogle Earthは、その場所を別タブで開きます。Google Earthの3D画面の埋め込み、Street View、自動ルート案内、GPSの現在地取得は含みません。

## 開発

Python 3とNode.js（標準機能のみ）を使います。

```sh
python3 scripts/build.py
node --test tests/core.test.cjs tests/schedule.test.cjs tests/learning.test.cjs
```

`src/lesson.json` が教材、`src/core.js` が検証と経路、`src/app.js` が画面、`src/style.css` が表示です。ビルドすると `dist/index.html` とルートの `index.html` が生成されます。Sites版は `dist` を配信します。

## 班別行動の予定表

「班の予定表」で、旅の記録から出発・到着・見学をコピーしたたたき台を作ります。学習した値のみをコピーし、新しい所要時間は計算しません。記録がない場合は見学プランの地点だけを並べ、未入力の時刻は空欄にします。

- ブラウザで開始・終了時刻、場所、活動、交通手段、計算した分、運賃、根拠、担当を編集できます。
- 昼食・休憩・集合などを追加し、行を上下に並べ替えられます（100行まで）。
- 時刻の重なりを確かめるヒントを出せます。時刻や時間を自動修正しません。
- Excelは本物の `.xlsx` で、予定表とお金の記録の2シートです。時刻は数値の時刻セルとして保存します。計算式は追加しません。
- Googleスプレッドシートには、CSVを「ファイル → インポート → アップロード」で取り込みます。アカウントへの直接自動作成・自動同期は行いません。
- 予定表と元の学習ノートは別の記録です。たたき台を作り直すと予定表を置き換えるため、先に書き出してください。

## デジタルおみやげ

23地点それぞれに学びにちなんだアイテムがあり、現地の学習画面で見学を完了してスタンプを押すと獲得します。ずかんを先読みしただけでは獲得せず、同じ場所で重複して増えません。先生はアイテム名と説明を編集できます。現地で使うGPSスタンプではなく、事前学習内の収集です。

## おこづかいモード

先生が持ち金を設定し、各場所の学習用の拝観料・入館料を設定します。料金は初期状態では未設定です。必要な場所で、学年・団体割引・実施日等に合う料金を公式資料で調べて入力してください。無料に設定するときは0円です。

モードを有効にすると、料金が設定された場所では、見学スタンプ前に児童が残金と計算の根拠を入力します。支払額と残金を記録し、引き算の答えは自動で出しません。同じ見学のメモを再保存しても二重に支払いを追加しません。

交通・食事・買い物などは「お金のノート」から追加・修正できます。残金は児童が入力した値であり、自動計算で保証された値ではありません。以前の支払いを直しても、その後の残金は班で見直します。Excelにはお金の記録も含めます。

## 境内探検とルビ（第2版）

鶴岡八幡宮の見学を、源氏池・平家池・太鼓橋・流鏑馬馬場・楼門の鳩の「八」・実朝と公暁の事件・大イチョウの7項目に分けています。見出しを開き、学習を終えたらチェックします。全7項目が完了して100％になるまで、見学終了スタンプは押せません。進み具合と項目ごとの発見メモは端末に保存し、提出用の記録JSONにも含めます。項目の文章と問いは、先生の準備室から編集できます。

本文・見出し・ボタン・地図の名称に読みを表示します。通常の文章にはHTMLのrubyを使い、地図内はSVGで読みを添えます。HTMLの選択欄はルビ表示ができないため、選択肢に読みを併記します。入力した文章はフォーカスを外すと、読み付きのプレビューを表示します。地名・人名は読みを個別指定しています。

先生が追加する固有名詞等の読みは、本文に `漢字《かんじ》` と入力して指定できます。アプリ内で辞書にない読みを外部APIへ送ることはありません。

`src/ruby-dictionary.json` は同梱済みです。ふだんのビルドに追加パッケージは不要です。教材・画面の語彙を追加して読みデータも再生成する開発時は、Janome 0.5.0を利用できる環境で `python3 scripts/build-readings.py` を実行し、`src/ruby-overrides.json` で固有名詞等を確認します。

## 切通と山道の学習ルート

銭洗弁財天宇賀福神社・源氏山公園・仮粧坂切通・大仏切通を追加しています。

- 鎌倉駅 → 仮粧坂切通 → 源氏山公園 → 銭洗弁財天 → 鎌倉駅。
- 鎌倉駅 → 銭洗弁財天 → 源氏山公園 → 大仏切通 → 鎌倉大仏 → 長谷駅。

紹介画面から見学プランに取り込めます。駅から源氏山へ合流する学習案であり、観光協会が掲載する「北鎌倉駅発」のコースの所要時間を、そのまま鎌倉駅発へ当てはめません。アプリは所要時間を計算せず、児童が資料を調べます。茶色の点線は山道を含む学習用のつながりです。実際の分岐や当日の通行可能区間を保証する線ではありません。現地で歩く計画は、先生の下見と最新の案内で確かめてください。

## GitHub用アイコン

`icon/` にSVG、ICO、16・32・48pxのPNG、180pxのApple用、192・512pxのアプリ用、512pxのマスク用をまとめています。`./icon/` の相対パスなので、GitHub Pagesのリポジトリ配下でも使えます。HTMLと一緒に `icon/` と `site.webmanifest` をアップロードしてください。詳細は `icon/README.md` にあります。

先生の準備室から書き出す1枚HTMLは、内蔵のSVGアイコンを使用します。マニフェストはアイコンと起動表示の設定用で、通信なしの実地図やサービスワーカーによるオフライン配信は含みません。
